# Data summary

`endoscapes_C1_counts.json` contains positive and negative C1 counts for each of 40 anonymous operations after the original frame screen (1,663 frames in total). Counts are sorted by positive count, then negative count. No source video identifiers, frame numbers, timestamps or individual annotator ratings are included.

The summary supports the pair-count illustration in Fig. 1. It cannot reconstruct the excluded frame list or replace local labels needed for the full audit.

Source: [Endoscapes2023, CAMMA](https://github.com/CAMMA-public/Endoscapes). Derived summary, shared under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Frame-level files and predictions are not distributed.
